# 🎬 Movie Recommendation System

A **content-based movie recommendation engine** built with Python and scikit-learn, using **TF-IDF vectorization** and **Cosine Similarity** to find movies with matching genre profiles. Includes a full step-by-step Jupyter Notebook and a polished **Streamlit** web application.

---

## 📁 Project Structure

```
├── Movie_Recommendation_Complete.ipynb   # Master notebook — build, tune & export the model
├── Movie_Recommender_App.py             # Streamlit web application
├── requirements.txt                     # Python dependencies
├── dataset/
│   ├── movies.csv                       # MovieLens movie catalogue (movieId, title, genres)
│   └── ratings.csv                      # User ratings (userId, movieId, rating, timestamp)
├── movies.pkl                           # Generated by notebook — cleaned movie dataframe

```

> ⚠️ **Run the notebook first.** `movies.pkl` and `similarity.pkl` must exist before launching the Streamlit app.

---

## ✨ Features

- **Content-Based Filtering** — recommends movies based on genre similarity, no user history required
- **TF-IDF Vectorization** — down-weights common genres and boosts distinctive ones (compared against CountVectorizer in notebook)
- **Cosine Similarity Matrix** — computes a pairwise similarity score for every movie pair in the catalogue
- **Popularity Boost** — configurable weight blends genre similarity with rating count (default 15% popularity, 85% similarity)
- **Genre Filter** — restrict recommendations to a single genre (Action, Comedy, Drama, etc.)
- **Fuzzy Title Matching** — partial, case-insensitive title lookup so small typos still work
- **Year Extraction & Decade Tagging** — year extracted from titles and added as a soft temporal signal
- **Diversity & Coverage Evaluation** — notebook computes average pairwise dissimilarity and catalogue coverage
- **Auto Dataset Download** — notebook auto-downloads MovieLens if `dataset/` folder is missing
- **Export** — Streamlit app lets users download recommendations as CSV

## 🧠 How It Works

### 1. Feature Engineering — `tags`

Each movie is described by a single text field built from:

```
tags = genres × 3 + decade
```

Genres are repeated three times to increase their TF-IDF weight. The decade (e.g. `decade1990`) adds a soft temporal signal so movies from the same era score slightly higher.

```
"Toy Story (1995)"  →  tags: "animation children comedy animation children comedy animation children comedy decade1990"
```

### 2. TF-IDF Vectorization

```
TfidfVectorizer(max_features=5000, ngram_range=(1,2), sublinear_tf=True)
```

- Each movie becomes a vector of up to 5,000 numbers
- Common genres (Drama, Comedy) get lower weights; rare genres (Film-Noir, Western) get higher weights
- Bigrams (`action adventure`, `sci fi`) capture genre combinations

### 3. Cosine Similarity

```
similarity[i][j] = cosine angle between vector i and vector j
  1.0 = identical genre profiles
  0.0 = no genres in common
```

The full N × N matrix is precomputed once in the notebook and saved to `similarity.pkl`.

### 4. Popularity Boost

```
final_score = (1 - weight) × similarity + weight × normalised_rating_count
```

| `popularity_weight` | Effect |
|---------------------|--------|
| `0.0` | 100% genre similarity (pure content-based) |
| `0.15` | 85% similarity + 15% popularity ← default |
| `0.50` | Equal mix |
| `1.0` | Popularity only (ignores genre match) |

## 📦 Dataset

This project uses the **MovieLens Latest Small** dataset from [GroupLens](https://grouplens.org/datasets/movielens/latest/).

The notebook auto-downloads it on first run. To download manually:

1. Visit https://grouplens.org/datasets/movielens/latest/
2. Download `ml-latest-small.zip`
3. Unzip and place `movies.csv` and `ratings.csv` inside a `dataset/` folder

**Dataset stats (ml-latest-small):**
- ~9,700 movies
- ~100,000 ratings
- 610 users
- Ratings range: 0.5 – 5.0
